# CodeAlpha Basic Chatbot

A simple rule-based chatbot built with Python for the CodeAlpha Python Programming Internship.

## Features
- Responds to `hello`, `how are you`, and `bye`.
- Uses predefined replies and simple `if-elif-else` conditions.
- Keeps chatting in a loop until the user types `bye`.
- Handles uppercase and lowercase input and ignores extra spaces around messages.
- Gives a helpful response for messages it does not recognize.

## Requirements
- Python 3.x
- No external packages required.

## Run
Open a terminal in this project folder and run:

```bash
python chatbot.py
```

## Example

```text
Basic Python Chatbot
Type 'hello', 'how are you', or 'bye' to chat.
You: hello
Bot: Hi!
You: how are you
Bot: I'm fine, thanks!
You: bye
Bot: Goodbye!
```
